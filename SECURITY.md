# Security

Lantern is read-only: it never holds keys, asks for seed phrases or requests wallet signatures. If you find a way it could be made to do any of those, or another vulnerability, please report it privately rather than in a public issue.

**How to report:** use GitHub's private vulnerability reporting ("Report a vulnerability" under the repository's Security tab). Include what you found, how to reproduce it and what an attacker could do with it.

You'll get a reply as soon as possible. Please give us a chance to fix the issue before disclosing it publicly.

## Not a vulnerability report

- A scam token Lantern didn't flag, or a legitimate token it flagged: open a normal issue with the chain and contract address.
- Someone impersonating Lantern in DMs: Lantern never messages anyone first. Report the account on that platform, and feel free to open an issue so we can warn others.
